Politique de confidentialité

Application mobile Appigeek — dernière mise à jour : octobre 2026

La présente politique décrit comment l’application Appigeek (« l’app ») traite les informations lorsque vous l’utilisez sur votre appareil iOS (ou Android le cas échéant).

1. Responsable et contact

Pour toute question relative à cette politique ou à vos données, vous pouvez nous écrire à l’adresse suivante : netfdorian@gmail.com.

2. Nature du service

Appigeek est une application de lecture de flux d’actualités (RSS et formats compatibles). Vous ajoutez vous‑même les adresses des flux que vous souhaitez suivre. Le contenu affiché provient des sites tiers que vous avez choisis ; nous ne publions pas ce contenu et ne sommes pas responsables des pratiques de ces sites.

3. Données stockées sur votre appareil

L’app enregistre localement, sans compte obligatoire :

  • la liste des flux auxquels vous êtes abonné ;
  • l’état de lecture (lus, favoris) et vos préférences (thème, police, langue) ;
  • éventuellement le texte d’articles téléchargés pour la lecture hors ligne ;
  • un identifiant anonyme local pour vos commentaires (permet de supprimer vos propres messages).

4. Compte Apple et synchronisation cloud (optionnel)

Si vous choisissez « Se connecter avec Apple », nous traitons un identifiant de compte (via Supabase Auth) afin de synchroniser vos abonnements, l’état de lecture et d’enregistrer un jeton de notification push pour les digests d’actualité. L’adresse e‑mail peut être masquée par Apple (« Hide My Email »).

Vous pouvez supprimer votre compte depuis Paramètres → Supprimer mon compte : cela efface le compte Auth, le profil cloud, les abonnements synchronisés, l’état de lecture cloud et les jetons push associés.

5. Commentaires

Les commentaires publiés dans l’app sont visibles par les autres utilisateurs (pseudo + message). Ils sont associés à un jeton anonyme local, pas à votre compte Apple. Après suppression de compte, les messages déjà publiés peuvent rester visibles sans lien vers votre identité.

6. Réseau et contenus tiers

Lorsque vous actualisez vos flux ou ouvrez un article, l’app contacte les serveurs correspondant aux URL que vous avez saisies (ou des ressources liées : images, pages web). Ces échanges se font entre votre appareil et ces tiers selon leurs propres politiques.

7. Publicités (Google AdMob)

L’application peut afficher des publicités fournies par Google via Google AdMob. Google peut collecter et traiter des données techniques conformément à sa politique.

Pour plus de détails : Politique de confidentialité Google.

8. Vos droits (RGPD)

Selon votre situation, vous pouvez demander l’accès, la rectification ou l’effacement de vos données personnelles.

  • Effacement du compte cloud : directement dans l’app (Paramètres → Supprimer mon compte).
  • Autres demandes : netfdorian@gmail.com.

9. Sécurité et enfants

Les données locales dépendent de la sécurité de votre appareil. L’app n’est pas destinée aux enfants de moins de 13 ans de manière spécifique.

10. Modifications

Nous pouvons mettre à jour cette politique. La date en tête de page sera actualisée ; consultez-la lorsque l’app signale une mise à jour importante.
